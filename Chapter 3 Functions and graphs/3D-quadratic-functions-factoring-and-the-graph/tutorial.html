Theory · key ideas

Every sketch in this section uses the same five questions.

  • 1 · Which way up? Look at a. Positive opens up. Negative opens down.
  • 2 · y-intercept. Put x=0.
  • 3 · Zeroes. Factor, put y=0, then set each factor to 0.
  • 4 · Axis. x=\dfrac{r+s}{2}. That is the average of the zeroes.
  • 5 · Vertex. Put the axis value of x back into the factored rule.
y=a(x-r)(x-s)

Most quadratics do not factor this easily. This section is only the factoring route. Later sections use other routes for the same five questions.

Worked mini-examples

Example · concave up

Sketch y=x^2-2x-3.

Quick fact: The number in front of x^2 is a. If a is positive, the parabola is concave up (it holds water). If a is negative, it is concave down.

1 · Which way up? In y=x^2-2x-3 the number in front of x^2 is 1, which is positive.

Quick fact: The y-intercept is the height where the curve crosses the y-axis. Put x=0.

2 · y-intercept. Put x=0 in x^2-2x-3.

y=0-0-3=-3

The curve crosses the y-axis at -3.

Quick fact: If A\times B=0, then A=0 or B=0. Each factor gives one zero (an x-intercept).

3 · Zeroes. Two numbers that multiply to -3 and add to -2 are -3 and 1. So y=(x+1)(x-3). Then x+1=0 or x-3=0.

The zeroes are x=-1 and x=3.

Quick fact: The axis of symmetry is the vertical line halfway between the zeroes. x=\dfrac{r+s}{2} means add the zeroes r and s, then divide by 2.

4 · Axis. Add -1 and 3, then divide by 2. The axis is halfway between the zeroes.

x=\dfrac{-1+3}{2}=1

The axis of symmetry is the line x=1.

Quick fact: The vertex is the turning point. It sits on the axis. Put that x back into the factored rule to get the height.

5 · Vertex. Put x=1 into the factored rule.

y=(1+1)(1-3)=2\times(-2)=-4

The vertex is (1,-4).

The sketch uses those five results: direction, y-intercept, zeroes, axis, and vertex.

Concave up, y-intercept -3, zeroes -1 and 3, axis x=1, vertex (1,-4).

Example · concave down

Same five questions for y=-x^2-2x+3.

Same fact: Positive a opens up. Negative a opens down.

1 · Which way up? The number in front of x^2 is -1, which is negative.

Same fact: The y-intercept is the height at x=0.

2 · y-intercept. Put x=0.

y=3

The curve crosses the y-axis at 3.

Same fact: A product is 0 only when one of the factors is 0.

3 · Zeroes. Factor out the minus: y=-(x^2+2x-3). Inside, numbers that multiply to -3 and add to 2 are 3 and -1. So y=-(x+3)(x-1).

The zeroes are x=-3 and x=1.

Same fact: The axis is the average of the zeroes: add them, then divide by 2.

4 · Axis. Add -3 and 1, then divide by 2.

x=\dfrac{-3+1}{2}=-1

The axis of symmetry is the line x=-1.

Same fact: Put the axis value of x back into the factored rule to get the vertex height.

5 · Vertex. Put x=-1 into the factored rule.

y=-(-1+3)(-1-1)=-(2)\times(-2)=4

The vertex is (-1,4).

The sketch uses those five results: direction, y-intercept, zeroes, axis, and vertex.

Concave down, y-intercept 3, zeroes -3 and 1, axis x=-1, vertex (-1,4).

Example · a double zero

y=-2(x-1)^2 touches the x-axis at one point.

Same fact: Positive a opens up. Negative a opens down.

1 · Which way up? The number in front is -2, which is negative.

Same fact: The y-intercept is the height at x=0.

2 · y-intercept. Put x=0.

y=-2(0-1)^2=-2(1)=-2

The curve crosses the y-axis at -2.

Same fact: A product is 0 only when one of the factors is 0.

3 · Zeroes. A square is 0 only when the inside is 0, so x=1. The factor is repeated. This is a double zero, and the curve just touches the x-axis.

The zeroes are x=1 only.

Same fact: The axis is the average of the zeroes: add them, then divide by 2.

4 · Axis. The only zero is 1, so the average is 1.

x=1

The axis of symmetry is the line x=1.

Same fact: Put the axis value of x back into the factored rule to get the vertex height.

5 · Vertex. The touch point is the vertex.

y=-2(1-1)^2=0

The vertex is (1,0).

Quick fact: Mirror the y-intercept in the axis. Same distance, other side, same height.

The y-intercept (0,-2) is 1 unit left of x=1. One unit to the right is (2,-2).

The sketch uses those five results: direction, y-intercept, zeroes, axis, and vertex.

Concave down, double zero at x=1, vertex (1,0), also through (0,-2) and (2,-2).

Example · same zeroes, two curves

Quick fact: y=a(x-r)(x-s) keeps the zeroes r and s. Only a changes.

Both curves below have zeroes x=-2 and x=4. The axis is x=\dfrac{-2+4}{2}=1 for both.

For a=1, the vertex height is (1+2)(1-4)=3\times(-3)=-9. For a=-\dfrac{1}{2}, the height is -\dfrac{1}{2}\times(-9)=\dfrac{9}{2}.

y=(x+2)(x-4) solid blue, concave up y=-\dfrac{1}{2}(x+2)(x-4) dashed teal, concave down

Same zeroes. The positive a opens up. The negative a opens down.

Example · domain and range

The domain of a quadratic is every real x. You may substitute any number.

The range is limited by the vertex. If the parabola opens up, the vertex is the lowest point, so y is at least that height. If it opens down, the vertex is the highest point, so y is at most that height.

The first example has vertex (1,-4) and opens up, so the range is y\ge -4.
