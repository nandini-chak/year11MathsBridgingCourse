1 · Exercise 3C Foundation

Follow these steps for the linear function y=2x-2.

(a) Find the y-intercept by putting x = 0.

(b) Find the x-intercept by putting y = 0.

(c) Plot these intercepts and sketch the line.

Quick fact: The y-intercept is where the line crosses the y-axis. Every point on the y-axis has x=0.

Start with y=2x-2.

Y-intercept: replace x with 0.

y=2\times 0-2=0-2=-2.

The y-intercept is the point (0,-2).

Quick fact: The x-intercept is where the line crosses the x-axis. Every point on the x-axis has y=0.

Start with y=2x-2.

X-intercept: replace y with 0.

2x-2=0.

Add 2 to both sides.

2x=2.

Divide both sides by 2.

x=\dfrac{2}{2}=1.

The x-intercept is the point (1,0).

Plot the point from (a) and the point from (b): (0, −2) and (1, 0).

Rule a straight line through them. Do not stop at the dots. A linear graph keeps going.

The line y = 2x − 2 crosses at (1, 0) and (0, −2).

8 · Exercise 3C Foundation

(a) State which lines in Question 7 are not functions.

(b) For each line that is not a function, write down the coordinates of two points on the line with the same x-coordinate.

Quick fact: A function gives exactly one y for each x you choose. If one x has two different y-values on the graph, it is not a function. A vertical line fails this test. A horizontal line passes it, because each x has only one y.

In Question 7, the vertical lines are (a) x = 1, (c) x = −2, and (f) x = 5/3.

Those three are not functions. The horizontal lines (b), (d) and (e) are functions.

Same test for each vertical line. Pick the intercept, then a second point with the same x and a different y. The pair (x, 0) and (x, 1) is enough.

For (a): (1,0) and (1,1). Both have x = 1, but the y-values are 0 and 1.

For (c): (-2,0) and (-2,1). Both have x = −2.

For (f): (\dfrac{5}{3},0) and (\dfrac{5}{3},1). Both have x = 5/3.

Each pair shows one x with two y-values, so those graphs are not functions.
