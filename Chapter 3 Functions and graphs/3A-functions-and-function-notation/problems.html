1 · Exercise 3A Foundation

Let f(x)=2x+3. Calculate the following function values.

(a) f(1)

(b) f(0)

(c) f(-2)

(d) f(4)

Quick fact: f(a) means replace every x in the rule with the number a.

f(1)=2\times 1+3=2+3=5.

f(1)=5.

Same method · Replace x with 0. f(0)=2\times 0+3=0+3=3.

f(0)=3.

Same method · Replace x with -2. f(-2)=2\times(-2)+3=-4+3=-1.

f(-2)=-1.

Same method · Replace x with 4. f(4)=2\times 4+3=8+3=11.

f(4)=11.

2 · Exercise 3A Foundation

Let p(x)=x^2-2x-3. Determine the following.

(a) p(0)   (b) p(4)   (c) p(3)   (d) p(-2)

Quick fact: Do the power first. 0^2=0. Then multiply. Then add and subtract from left to right.

p(0)=0^2-2\times 0-3=0-0-3=-3.

p(0)=-3.

Same method · p(4)=4^2-2\times 4-3=16-8-3=5.

p(4)=5.

Same method · p(3)=3^2-2\times 3-3=9-6-3=0.

p(3)=0.

Same method · (-2)^2=4, and -2\times(-2)=+4.

p(-2)=4-2\times(-2)-3=4+4-3=5.

p(-2)=5.

3 · Exercise 3A Foundation

Find the value of y=5+2x-x^2 at each value of x.

(a) 0   (b) 5   (c) -2   (d) -1

Quick fact: The letter y is the output. Replace x, square first, then multiply, then add.

y=5+2\times 0-0^2=5+0-0=5.

When x=0, y=5.

Same method · y=5+2\times 5-5^2=5+10-25=-10.

When x=5, y=-10.

Same method · (-2)^2=4 and 2\times(-2)=-4.

y=5+2\times(-2)-(-2)^2=5-4-4=-3.

When x=-2, y=-3.

Same method · (-1)^2=1 and 2\times(-1)=-2.

y=5+2\times(-1)-(-1)^2=5-2-1=2.

When x=-1, y=2.

4 · Exercise 3A Foundation

Find h(-3), h(1) and h(5) for each function.

(a) h(x)=2x+2

(b) h(x)=\dfrac{1}{x}

(c) h(x)=3x-x^2

(d) h(x)=\sqrt{x+4}

Quick fact: For each input, replace x and calculate. Do all three the same way.

h(-3)=2\times(-3)+2=-6+2=-4.

h(1)=2\times 1+2=4.

h(5)=2\times 5+2=12.

-4,\; 4,\; 12.

Quick fact: \dfrac{1}{x} means 1 divided by the input. A negative input gives a negative output.

h(-3)=\dfrac{1}{-3}=-\dfrac{1}{3}.

h(1)=\dfrac{1}{1}=1.

h(5)=\dfrac{1}{5}.

-\dfrac{1}{3},\; 1,\; \dfrac{1}{5}.

Same method · Square first, then subtract that square from 3x.

h(-3)=3\times(-3)-(-3)^2=-9-9=-18.

h(1)=3\times 1-1^2=3-1=2.

h(5)=3\times 5-5^2=15-25=-10.

-18,\; 2,\; -10.

Quick fact: \sqrt{\ } means “what number times itself gives the inside?” Add 4 to x first, then take the square root.

h(-3)=\sqrt{-3+4}=\sqrt{1}=1.

h(1)=\sqrt{1+4}=\sqrt{5}. 5 is not a perfect square, so leave it as \sqrt{5}.

h(5)=\sqrt{5+4}=\sqrt{9}=3.

1,\; \sqrt{5},\; 3.

5 · Exercise 3A Foundation

Write down g(t) for each function. The letter t is just another name for the input.

(a) g(x)=3x+1

(b) g(x)=x^2-2x+8

(c) g(x)=x-\sqrt{x}

Quick fact: g(t) means replace every x with t. There is no number to calculate, so the answer stays in terms of t.

g(t)=3t+1.

Same method · Replace each x with t.

g(t)=t^2-2t+8.

Same method · Both the plain x and the x inside the square root become t.

g(t)=t-\sqrt{t}.

6 · Exercise 3A Foundation

In each case do the given substitution, then expand and simplify.

(a) y=2-x at x=p-1

(b) y=2x-5 at x=q+2

(c) y=x^2-x at x=a+1

(d) y=x^2-3x-4 at x=b-2

Quick fact: Replacing x with a bracket means the whole bracket goes in. A minus in front of a bracket changes the sign of each term inside.

y=2-(p-1)=2-p+1=3-p.

y=3-p.

Same method · y=2(q+2)-5=2q+4-5=2q-1.

y=2q-1.

Formula: (a+1)^2=a^2+2a+1.

y=(a+1)^2-(a+1)=a^2+2a+1-a-1.

a^2 stays. 2a-a=a. 1-1=0.

y=a^2+a.

Formula: (b-2)^2=b^2-4b+4. Minus a bracket: -3(b-2)=-3b+6.

y=(b-2)^2-3(b-2)-4=b^2-4b+4-3b+6-4.

b terms: -4b-3b=-7b. Numbers: 4+6-4=6.

y=b^2-7b+6.

For L(x)=3x+1, determine:

(a) L(1)-2   (b) 3L(-1)   (c) L(1)+L(2)   (d) L(9)\div L(2)

Quick fact: Work out the function value first. Then do the extra arithmetic outside the brackets.

L(1)=3\times 1+1=4.

L(1)-2=4-2=2.

2.

Same method · Find L(-1) first, then multiply that output by 3.

L(-1)=3\times(-1)+1=-3+1=-2.

3L(-1)=3\times(-2)=-6. Three times a negative number is negative.

-6.

Same method · Find each output, then add them.

L(1)=4. L(2)=3\times 2+1=7.

L(1)+L(2)=4+7=11.

11.

Same method · Find each output, then divide.

L(9)=3\times 9+1=28. L(2)=7.

28\div 7=4.

10 · Exercise 3A Development

Given P(x)=x^2-2x-4, find:

(a) P(\sqrt{2})   (b) P(\sqrt{7})

Quick fact: (\sqrt{2})^2=2. A square root and a square undo each other.

P(\sqrt{2})=(\sqrt{2})^2-2\sqrt{2}-4=2-2\sqrt{2}-4.

Numbers: 2-4=-2. The -2\sqrt{2} stays, because \sqrt{2} is not a whole number.

P(\sqrt{2})=-2-2\sqrt{2}.

Same method · (\sqrt{7})^2=7.

P(\sqrt{7})=7-2\sqrt{7}-4=3-2\sqrt{7}.

P(\sqrt{7})=3-2\sqrt{7}.

11 · Exercise 3A Development

(a) Write 3x+4y+5=0 as a function with independent variable x.

(b) Write 3x+4y+5=0 as a function with independent variable y.

(c) Write 4+xy=0 as a function with dependent variable y.

(d) The volume of a cube with side s is V=s^3, and its surface area is A=6s^2. Write each formula as a function with dependent variable s.

(e) A rectangle has area 100\,\mathrm{m}^2 and sides \ell and b, so \ell b=100. Write this with

(i) \ell as the dependent variable   (ii) \ell as the independent variable.

Quick fact: Independent variable x means x is the input, so make y the subject (get y alone).

Subtract 3x+5 from both sides: 4y=-3x-5.

Divide by 4: y=\dfrac{-3x-5}{4}.

y=\dfrac{-3x-5}{4}.

Same idea · Independent variable y means make x the subject.

3x=-4y-5, so x=\dfrac{-4y-5}{3}.

x=\dfrac{-4y-5}{3}.

Dependent variable y means y is the output. Get y alone.

xy=-4, so y=\dfrac{-4}{x}, provided x\neq 0.

y=-\dfrac{4}{x}.

Quick fact: Dependent variable s means s is the output. Undo a cube with a cube root. Undo a square with a square root. A side length is positive.

From V=s^3, s=\sqrt[3]{V}.

From A=6s^2, s^2=\dfrac{A}{6}, so s=\sqrt{\dfrac{A}{6}}.

s=\sqrt[3]{V} and s=\sqrt{\dfrac{A}{6}}.

Dependent \ell means get \ell alone. Divide both sides of \ell b=100 by b.

\ell=\dfrac{100}{b}, with b\neq 0.

Same formula, other letter out · Independent \ell means \ell stays on the right. Get b alone.

b=\dfrac{100}{\ell}, with \ell\neq 0.

13 · Exercise 3A Development

In each case explain why the function value cannot be found.

(a) F(0), where F(x)=\sqrt{x-4}

(b) H(3), where H(x)=\sqrt{1-x^2}

(c) g(-2), where g(x)=\dfrac{1}{2+x}

(d) f(0), where f(x)=\dfrac{1}{x}

Quick fact: In this course, the square root of a negative number is not a real number. The value is undefined.

F(0)=\sqrt{0-4}=\sqrt{-4}.

Inside the square root is negative, so F(0) cannot be found.

Same idea · H(3)=\sqrt{1-3^2}=\sqrt{1-9}=\sqrt{-8}.

Inside the square root is negative, so H(3) is not a real number.

Quick fact: A fraction with denominator 0 is undefined. You cannot divide by zero.

g(-2)=\dfrac{1}{2+(-2)}=\dfrac{1}{0}.

The denominator is 0, so g(-2) cannot be found.

Same idea · f(0)=\dfrac{1}{0}.

The denominator is 0, so f(0) cannot be found.

14 · Exercise 3A Development

Find g(a), g(-a) and g(a+1) for each function.

(a) g(x)=2x-4

(b) g(x)=2-x

(c) g(x)=x^2

(d) g(x)=\dfrac{1}{x-1}

Quick fact: Put the whole new input in place of x. For g(-a), the input is -a. For g(a+1), the input is the bracket (a+1).

g(a)=2a-4.

g(-a)=2\times(-a)-4=-2a-4.

g(a+1)=2(a+1)-4=2a+2-4=2a-2.

2a-4,\; -2a-4,\; 2a-2.

Same method · g(a)=2-a.

g(-a)=2-(-a)=2+a.

g(a+1)=2-(a+1)=2-a-1=1-a.

2-a,\; 2+a,\; 1-a.

Formula: (-a)^2=a^2 and (a+1)^2=a^2+2a+1.

g(a)=a^2.

g(-a)=(-a)^2=a^2.

g(a+1)=(a+1)^2=a^2+2a+1.

a^2,\; a^2,\; a^2+2a+1.

g(a)=\dfrac{1}{a-1}.

g(-a)=\dfrac{1}{-a-1}=-\dfrac{1}{a+1}.

g(a+1)=\dfrac{1}{(a+1)-1}=\dfrac{1}{a}.

\dfrac{1}{a-1},\; -\dfrac{1}{a+1},\; \dfrac{1}{a}.

15 · Exercise 3A Development

Find F(t)-2 and F(t-2) for each function. These are different jobs.

(a) F(x)=5x+2

(b) F(x)=\sqrt{x}

(c) F(x)=x^2+2x

(d) F(x)=2-x^2

Quick fact: F(t)-2 means find the output, then subtract 2. F(t-2) means change the input to t-2 before you use the rule.

F(t)=5t+2, so F(t)-2=5t+2-2=5t.

F(t-2)=5(t-2)+2=5t-10+2=5t-8.

5t and 5t-8.

Same method · F(t)=\sqrt{t}, so F(t)-2=\sqrt{t}-2. The -2 is outside the square root.

F(t-2)=\sqrt{t-2}. The -2 is inside the square root.

\sqrt{t}-2 and \sqrt{t-2}.

Formula: (t-2)^2=t^2-4t+4.

F(t)=t^2+2t, so F(t)-2=t^2+2t-2.

F(t-2)=(t-2)^2+2(t-2)=t^2-4t+4+2t-4=t^2-2t.

t^2+2t-2 and t^2-2t.

Same method · F(t)=2-t^2, so F(t)-2=2-t^2-2=-t^2.

F(t-2)=2-(t-2)^2=2-(t^2-4t+4)=2-t^2+4t-4=-t^2+4t-2.

-t^2 and -t^2+4t-2.

16 · Exercise 3A Challenge

Again using P(x)=x^2-2x-4, find:

(a) P(1+\sqrt{5})   (b) P(\sqrt{3}-1)

Formula: (1+\sqrt{5})^2=1+2\sqrt{5}+5=6+2\sqrt{5}. Also (\sqrt{5})^2=5.

P(1+\sqrt{5})=(1+\sqrt{5})^2-2(1+\sqrt{5})-4.

=6+2\sqrt{5}-2-2\sqrt{5}-4.

The 2\sqrt{5} and -2\sqrt{5} cancel. Numbers: 6-2-4=0.

P(1+\sqrt{5})=0.

Formula: (\sqrt{3}-1)^2=3-2\sqrt{3}+1=4-2\sqrt{3}.

P(\sqrt{3}-1)=(\sqrt{3}-1)^2-2(\sqrt{3}-1)-4.

=4-2\sqrt{3}-2\sqrt{3}+2-4.

Square-root terms: -2\sqrt{3}-2\sqrt{3}=-4\sqrt{3}. Numbers: 4+2-4=2.

P(\sqrt{3}-1)=2-4\sqrt{3}.

17 · Exercise 3A Challenge

If f(x)=x^2+5x, find in simplest form:

(a) \dfrac{f(1+h)-f(1)}{h}

(b) \dfrac{f(p)-f(q)}{p-q}

(c) \dfrac{f(x+h)-f(x)}{h}

Quick fact: This fraction is “change in output, divided by change in input”. Work out the top fully before you divide. We need h\neq 0, or the denominator is zero.

f(1)=1^2+5\times 1=6.

f(1+h)=(1+h)^2+5(1+h)=1+2h+h^2+5+5h=h^2+7h+6.

Top: h^2+7h+6-6=h^2+7h=h(h+7).

Divide by h: \dfrac{h(h+7)}{h}=h+7.

h+7.

Formula: p^2-q^2=(p-q)(p+q). We need p\neq q.

f(p)=p^2+5p and f(q)=q^2+5q.

Top: p^2+5p-q^2-5q=(p^2-q^2)+5(p-q)=(p-q)(p+q)+5(p-q).

Factor p-q: (p-q)(p+q+5).

Divide by p-q: p+q+5.

p+q+5.

Same method as (a) · Replace the input 1 with a general x. Need h\neq 0.

f(x+h)=(x+h)^2+5(x+h)=x^2+2xh+h^2+5x+5h.

f(x)=x^2+5x, so the top is x^2+2xh+h^2+5x+5h-x^2-5x=2xh+h^2+5h.

Factor h: h(2x+h+5). Divide by h.

2x+h+5.

18 · Exercise 3A Challenge

(a) If f(x)=x^4+2x^2+3, show that f(-x)=f(x) for all x.

(b) If g(x)=x^3+\dfrac{4}{x}, show that g(-x)=-g(x) whenever x\neq 0.

(c) If h(x)=\dfrac{x}{x^2+1}, show that h\!\left(\dfrac{1}{x}\right)=h(x) whenever x\neq 0.

Quick fact: An even power of a negative number is positive. (-x)^2=x^2 and (-x)^4=x^4.

f(-x)=(-x)^4+2(-x)^2+3=x^4+2x^2+3.

That is exactly f(x).

f(-x)=f(x) for every x.

Quick fact: An odd power keeps the minus. (-x)^3=-x^3. Also \dfrac{4}{-x}=-\dfrac{4}{x}. We already need x\neq 0 so that \dfrac{4}{x} exists.

g(-x)=(-x)^3+\dfrac{4}{-x}=-x^3-\dfrac{4}{x}.

-g(x)=-\left(x^3+\dfrac{4}{x}\right)=-x^3-\dfrac{4}{x}.

Both sides match, so g(-x)=-g(x) when x\neq 0.

Replace the input x with \dfrac{1}{x}. Need x\neq 0, or \dfrac{1}{x} does not exist.

h\!\left(\dfrac{1}{x}\right)=\dfrac{\frac{1}{x}}{\left(\frac{1}{x}\right)^2+1}=\dfrac{\frac{1}{x}}{\frac{1}{x^2}+1}.

The denominator is \dfrac{1}{x^2}+\dfrac{x^2}{x^2}=\dfrac{1+x^2}{x^2}.

Dividing by that fraction means multiply by its reciprocal: \dfrac{1}{x}\times\dfrac{x^2}{1+x^2}=\dfrac{x}{1+x^2}.

That is h(x), so h\!\left(\dfrac{1}{x}\right)=h(x) when x\neq 0.
