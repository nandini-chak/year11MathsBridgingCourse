3A · Functions and function notation

Direct path: Concept → Tutorial → Exercise.

What this section is about

A function is a rule: put a number in, and the rule gives exactly one number out.

  • Picture it: an electrician charges \$100 to visit, then \$40 for each power point. If x power points are installed, the cost is y=100+40x.
  • Input and output: x is the independent variable (you choose it). y is the dependent variable (it depends on x).
  • Name the rule: f(x)=100+40x is read “f of x”. f(2)=180 means “when the input is 2, the output is 180”.
  • Swap the input: f(a) means replace every x with a. f(a+1) means replace every x with the whole bracket (a+1).
  • Sometimes the input is not allowed: you cannot divide by zero, and you cannot take the square root of a negative number in this course.

Full detail and tiny worked examples live in the Tutorial · theory. This page only sets the scene.

Prior knowledge — quick notes

Keep these in mind. The Tutorial shows each one with numbers.

  • Substitute: replace the letter with the number, then calculate.
  • A square: (-3)^2=9. The minus disappears because negative times negative is positive.
  • Expand (a+h)^2=a^2+2ah+h^2.
  • Order: brackets first, then powers, then multiply, then add.
