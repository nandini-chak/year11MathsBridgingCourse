3B · Functions, relations, and graphs

Short key ideas and tiny worked examples. Read one example, then try the same steps on the Exercise.

Theory · key ideas

Plot pairs. If each x has only one y, the picture is a function.

  • Table to points: each column of a table is one pair (x, y).
  • Join them: in this course the pairs usually join into a smooth curve. There are many more pairs than the ones in the table.
  • Function test: no two points have the same x. A vertical line must not hit the graph twice.
  • Domain: all the x-coordinates that appear. Range: all the y-coordinates that appear.
  • Dots: a filled dot means that end is included. An open dot means that end is not included.
  • Relation: any collection of pairs. A function is a relation that passes the vertical-line test.

Worked mini-examples

Example · a ball, a table, and filled ends

Question

A ball is thrown straight up. Its height y metres, x seconds after the throw, is y=5x(6-x).

The ball leaves the ground at x=0 and is back on the ground at x=6.

a Make a table for x=0,1,2,3,4,5,6.

b List the ordered pairs and sketch the graph. Use a filled dot at each end.

c Write the domain and the range.

d Does any vertical line hit the graph twice? Is the graph a function?

Solution

Formula: height y=5x(6-x) metres, x seconds after the throw. Multiply 5 by x, then by (6-x).

Step 1 · Build a table. One check: when x=2, y=5\times 2\times(6-2)=10\times 4=40.

x (seconds)0123456
y (metres)025404540250

Step 2 · The seven pairs are (0,0),\ (1,25),\ (2,40),\ (3,45),\ (4,40),\ (5,25),\ (6,0). Plot them and join with a smooth curve.

Step 3 · The ball has not been thrown when x is negative, and it is back on the ground at x=6. So the domain is 0\le x\le 6, written [0, 6]. The square brackets mean both ends count. The filled dots on the graph say the same thing.

Step 4 · The heights run from 0 up to 45 and back to 0. The range is 0\le y\le 45, written [0, 45].

Step 5 · At each time there is only one height, so no vertical line hits this curve twice. It is a function.

Example · read domain and range off a graph

Question

Write down the domain and the range of each function.

Solution

Quick fact: Domain = the x-values that have a point of the graph above or below them. Range = the y-values that have a point of the graph to the left or right.

a · The curve is a hill. The highest point is on the y-axis at height 4, so that point is (0, 4). Both ends keep going down, with no filled dot to stop them, so every x is used. The domain is all real x, written (-\infty, \infty).

The highest y is 4, and that top point is included. The curve goes down without a bottom, so the range is y\le 4, written (-\infty, 4]. The square bracket sits next to 4 because 4 is included.

b · Same idea, new graph. Filled dots mark the two ends: (-2, -8) and (2, 8). The curve does not go past those ends, so the domain is -2\le x\le 2, written [-2, 2].

The lowest y is -8 and the highest is 8. Both dots are filled, so both heights count. The range is -8\le y\le 8, written [-8, 8].

Example · natural domain from a formula

Question

Find the natural domain of each function. Nobody has written an extra restriction.

a y=\dfrac{1}{x-2}

b y=\sqrt{x-2}

Solution

Quick fact: If nobody writes a restriction, the natural domain is every x the formula will accept.

a · y=\dfrac{1}{x-2}. The bottom of a fraction cannot be 0.

x-2\neq 0, so x\neq 2. Every other real number is allowed.

b · Same idea, new block. y=\sqrt{x-2}. The inside of a square root cannot be negative.

x-2\ge 0, so x\ge 2. That is the interval [2, \infty).

Example · a relation that fails the vertical-line test

Question

Each graph is a relation. Show that it is not a function: write two ordered pairs with the same x-coordinate, and join those points with a vertical line. Then write the domain and the range.

a x^2+y^2=25

b y^2=x

Solution

Quick fact: A relation is any set of pairs. It is a function only when no x is used twice. x^2+y^2=r^2 is a circle, centre (0,0), radius r.

a · Step 1 · Here r^2=25, so r=5 (radius is positive). The circle has radius 5 and centre (0, 0). Both (0, 5) and (0, -5) are on it, because 0^2+5^2=25 and 0^2+(-5)^2=25.

Step 2 · Those two points have the same x, namely x=0. The input 0 would have two outputs, 5 and -5.

Step 3 · The red vertical line is x=0. It hits the circle twice. One hit is enough to say: this relation is not a function.

Step 4 · x runs from -5 to 5, and so does y. Domain [-5, 5]. Range [-5, 5].

b · Same idea, new curve. y^2=x means x is a square, so x cannot be negative. The curve starts at (0, 0) and opens to the right.

Put x=1. Then y^2=1. A square can be 1 in two ways: 1^2=1 and (-1)^2=1. So both (1, 1) and (1, -1) are on the graph.

Those two points have the same x. The input 1 would have two outputs, 1 and -1. The red vertical line is x=1. It hits the curve twice, so this relation is not a function.

x starts at 0 and keeps going right: domain x\ge 0, written [0, \infty). y goes up and down with no top and no bottom: range all real y, written (-\infty, \infty).
