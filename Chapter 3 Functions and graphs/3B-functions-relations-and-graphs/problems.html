(f) f(x)=\sqrt{2x+1}

Jordan bends a 20 cm piece of wire into a rectangle. Let x be the length of one side, in centimetres.

(a) What is the length of the opposite side?

(b) What is the length of each of the other two sides?

(c) Find the area A as a function of x.

(d) Use the fact that lengths must be positive to find the domain of A.

(e) Use a table of values to graph A on that domain.

(a)

Opposite sides of a rectangle are equal. One side is x cm, so the side opposite it is also x cm.

x cm.

(b)

Quick fact: The perimeter is the distance around the shape. A rectangle’s perimeter is 2\times(\text{length}+\text{width}).

The wire is 20 cm, so the perimeter is 20.

Two sides of length x use 2x cm. The leftover wire is 20-2x cm.

That leftover is the other two equal sides together. Each one is half of it: \dfrac{20-2x}{2}=10-x.

Each of the other sides is 10-x cm.

(c)

Formula: area of a rectangle = length × width.

The sides are x and 10-x.

A=x(10-x)=10x-x^2.

A(x)=10x-x^2.

(d)

A length must be positive, so x>0.

The other side must be positive too: 10-x>0, so x<10.

Both must be true at once. If x=0 or x=10, one side has length 0, which is not a rectangle with a positive side.

Domain of A: 0<x<10, or (0, 10).

(e)

Formula: A=x(10-x). Multiply x by (10-x).

x=2: A=2\times 8=16. x=5: A=5\times 5=25. x=8: A=8\times 2=16.

The graph is a hill. The highest point in the table is (5, 25). Because the domain does not include 0 or 10, the ends near (0, 0) and (10, 0) are open dots.

Solve each equation for y, and use that to show the equation gives a function.

(a) 2x-y+3=0   (b) xy=4   (c) xy-2y=3   (d) y+2=\sqrt{9-x^2}

(a)

Start with 2x-y+3=0.

Add y to both sides: 2x+3=y.

So y=2x+3. Each input x gives one output.

It is a function.

(b)

Quick fact: If x is not 0, dividing both sides by x is allowed.

xy=4.

Divide by x: y=\dfrac{4}{x}.

For each allowed x there is one y.

It is a function (natural domain x\neq 0).

(c)

Both terms on the left have a factor y. Factor it out: y(x-2)=3.

Divide by (x-2), which we can do when x\neq 2: y=\dfrac{3}{x-2}.

Each allowed x gives one y.

It is a function.

(d)

Quick fact: The square-root sign means one value only: 0, or a positive number. It does not give the negative root as well.

y+2=\sqrt{9-x^2}.

Subtract 2: y=\sqrt{9-x^2}-2.

The right-hand side is one number for each allowed x, so there is one y.

It is a function.

16 · Exercise 3B Challenge

State the natural domain of each function.

(a) f(x)=\dfrac{x}{\sqrt{x+2}}

Quick fact: If a square root is on the bottom of a fraction, the inside must be positive. Zero is not allowed, because we cannot divide by 0. A negative inside is not a real square root.

The inside is x+2. It must be positive, not zero.

x+2>0, so x>-2.

Check the edge: if x=-2, the bottom is \sqrt{0}=0, and we cannot divide by 0. If x=-3, the inside is -1, which has no real square root.

Natural domain: x>-2, or (-2, \infty).

(b) f(x)=\dfrac{2}{x^2-4}

Formula: x^2-4=(x-2)(x+2). A product is 0 when one factor is 0.

The bottom is 0 when (x-2)(x+2)=0.

So x-2=0 or x+2=0. That is x=2 or x=-2.

Natural domain: all real x except -2 and 2.

(c) f(x)=\dfrac{1}{x^2+x}

Formula: x^2+x=x(x+1). Factor out the common x.

The bottom is 0 when x(x+1)=0.

So x=0 or x+1=0, that is x=-1.

Both of those inputs must be left out. Leaving out only x=-1 would still include a division by zero at x=0.

Natural domain: all real x except 0 and -1.

(d) f(x)=\dfrac{1}{x^2-5x+6}

Formula: look for two numbers that multiply to 6 and add to -5. They are -2 and -3, so x^2-5x+6=(x-2)(x-3).

The bottom is 0 when x-2=0 or x-3=0.

So x=2 or x=3.

Natural domain: all real x except 2 and 3.

(e) f(x)=\sqrt{x^2-4}

Quick fact: \sqrt{\text{inside}} is a real number only when the inside is 0 or bigger.

The inside must be 0 or bigger: x^2-4\ge 0.

Add 4: x^2\ge 4.

Which numbers have a square at least 4? 2^2=4 and (-2)^2=4. Numbers further out are bigger: 3^2=9 and (-3)^2=9. Numbers in between are too small: 0^2=0, and 0-4=-4, which is negative, so x=0 is not allowed.

The allowed inputs are x\le -2 or x\ge 2. The ends are included because the inside is 0 there, and \sqrt{0}=0.

Natural domain: (-\infty, -2]\cup[2, \infty).

(f) f(x)=\dfrac{1}{\sqrt{1-x^2}}

Quick fact: If a square root is on the bottom of a fraction, the inside must be positive. Zero is not allowed, because we cannot divide by 0. A negative inside is not a real square root.

The inside must be positive: 1-x^2>0.

Add x^2: 1>x^2. The numbers whose square is less than 1 are the numbers strictly between -1 and 1.

Check the ends. If x=1, the bottom is \sqrt{0}=0. Division by zero is not allowed. Same at x=-1. If x=0, f(0)=\dfrac{1}{\sqrt{1}}=1, which is allowed.

Natural domain: -1<x<1, or (-1, 1).
