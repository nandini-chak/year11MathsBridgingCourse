Chapter 3 · Functions and graphs

3B · Functions, relations, and graphs

Direct path: Concept → Tutorial → Exercise.

What this section is about

A graph is a picture of pairs (x, y). A function is the special picture where each x appears only once.

  • Picture it: a ball is thrown up. After x seconds its height is y=5x(6-x) metres, and only for 0\le x\le 6. Plot the pairs and join them. The ends are filled dots, because x=0 and x=6 are included.
  • One output: at one moment the ball has one height. On the graph, no two points share the same x.
  • Domain and range: the domain is the set of x-values used. The range is the set of y-values used. For the ball, domain [0, 6] and range [0, 45].
  • Relation: any set of pairs. A circle is a relation, but not a function, because one x can give two heights. A vertical line that hits the picture twice shows that.
  • Natural domain: if no restriction is written, use every x that the formula will accept. You still cannot divide by zero, and you still cannot square-root a negative number.

Full detail and tiny worked examples live in the Tutorial · theory. This page only sets the scene.

Prior knowledge — quick notes

Keep these in mind. The Tutorial shows each one with numbers.

  • An ordered pair (x, y): go across by x, then up by y.
  • From 3A: a function gives exactly one output for each allowed input.
  • [0, 6] includes the ends. (0, 6) does not.
  • You cannot divide by 0. You cannot take the square root of a negative number.
  • A vertical line is straight up and down. Every point on it has the same x.
